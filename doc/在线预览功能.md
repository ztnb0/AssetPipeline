```
搜索外部素材
    ↓
点击素材卡片
    ↓
弹出在线预览窗口
    ├─ 图片：加载外部图片 URL
    └─ 视频：加载外部视频 URL
    ↓
用户满意后点击“导入素材库”
    ↓
才调用现有导入接口，下载到 MinIO 并进行 AI 分析
```

包图网素材的按钮显示为“VIP 下载并导入素材库”。搜索与预览使用公开数据，不会消耗下载权益；点击导入后才由服务端使用当前会员令牌校验并下载。

## 图片预览

```
搜索结果卡片
    ↓ 点击
站内图片预览弹窗
    ↓
通过外部图片 URL 显示较大尺寸图片或原图
```

卡片继续使用缩略图，以减少列表加载流量。

预览弹窗使用 Provider 提供的较大尺寸图片 URL：

- Pexels：优先 `large2x`、`large`，必要时使用 `original`。
- Pixabay：优先 `largeImageURL`。
- Unsplash：优先 `regular`，原图可按需使用 `full`。
- Openverse：优先原始图片地址；访问失败时回退缩略图。
- 包图网：列表与弹窗使用公开预览图；中文关键词先转换为官网拼音检索词，并使用官网“全部”分类参数保持结果顺序一致。

弹窗提供：

- 大图预览。
- 图片名称、作者、来源、尺寸和许可。
- “查看原始页面”按钮。
- “导入素材库”按钮。

## 视频预览

```
搜索结果卡片
    ↓ 点击
站内视频预览弹窗
    ↓
浏览器在线播放外部视频
```

卡片仍使用视频封面，避免列表页加载大量视频。

预览弹窗中使用：

```
<video controls preload="metadata">
```

视频来源：

- Pexels：从 `video_files` 中选择适合预览的 MP4。
- Pixabay：优先 `videos.medium.url`，回退 `small.url`。
- Mixkit：点击预览时由后端解析详情页，返回适合预览的视频地址。
- 包图网：使用公开封面和视频预览地址，不需要跳转包图网页即可在弹窗播放。

弹窗提供：

- 视频播放器和封面。
- 标题、作者、来源、时长、分辨率和许可。
- “查看原始页面”按钮。
- “导入素材库”按钮。

## 包图网 VIP 导入与原文件

包图网搜索结果可见不等于当前账号有下载权限。导入流程如下：

```text
点击“VIP 下载并导入素材库”
    ↓
接口立即返回任务 ID，前端开始轮询进度
    ↓
后台通过 IBAOTU_ID_TOKEN 调用 validpackage 校验权益
    ↓
权益有效：显示下载百分比、解压中和入库进度
权益无效：显示包图网返回的不可下载原因，不保存素材
```

令牌只保存在服务端 `.env`，不得发送到浏览器或提交到 Git。授权原文件默认最大 `1024` MB，可通过 `IBAOTU_MAX_DOWNLOAD_MB` 调整；该限制独立于普通上传的 `MAX_UPLOAD_MB`。

导入后，预览和 AI 分析从 `/api/assets/{id}/content` 读取官方授权包内提取的无水印图片或视频。完整 ZIP 仅作为导入过程中的临时文件，提取完成后立即删除，不在素材详情中提供源包下载。如果授权包内没有浏览器支持的媒体，导入会明确失败，不会使用带水印公开预览替代。

本地视频的 `/content` 支持 HTTP Range 分段读取。后台分析同时生成最大 1080p 的 H.264/AAC faststart MP4 代理用于网页播放，避免浏览器为了读取 MOV 尾部索引而先下载完整 4K 原片；原始视频仍保存在 MinIO。

每个导入任务拥有独立的前端进度状态。下载过程中预览弹窗仍可关闭，其他素材的导入按钮保持可用，因此用户可以并行提交多个图片或视频；关闭预览只改变界面，不会取消已经提交到后端的任务。
