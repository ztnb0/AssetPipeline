### 2.3 验证与使用

1. 打开浏览器访问 **http://localhost:8787**
2. 健康检查：`http://localhost:8787/health`（返回 `status: ok`、探测到的技能目录与 akshare python）
3. 在页面输入一句话（如「对比中美近几年的黄金储备量」）→ 点「生成图表」
4. 轮询任务状态 → 完成后在 iframe 预览，点「下载 HTML」保存 `chart.html`

> 每张图约 2–5 分钟，消耗模型额度；后端并发上限默认 1（`.env` 的 `C2C_MAX_CONCURRENT`）。

### 2.4 配置项（`.env`，从 `.env.example` 复制）

| 变量 | 当前值 / 示例 | 作用 |
| --- | --- | --- |
| `C2C_PORT` | `8787` | 服务端口 |
| `C2C_MAX_CONCURRENT` | `1` | 最大并发任务数 |
| `C2C_JOB_TIMEOUT` | `1500` | 单任务超时（秒） |
| `OPENCODE_BIN` | `...\opencode-ai\bin\opencode.exe` | opencode 可执行文件路径 |
| `C2C_MODEL` | `company/Qwen3.5-35B-A3B` | 生成图表所用模型（可改 `deepseek/deepseek-v4-pro` 等） |
| `LIEFLAT_SKILL_PATH` | 留空自动探测 | lieflat-charts 技能目录 |
| `AKSHARE_PYTHON` | 留空自动探测 | 取数 Python 解释器 |
| `C2C_DATA_DIR` | 留空 | 任务数据目录（默认 `chat2chart/data`） |

### 2.5 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 健康检查 |
| POST | `/api/jobs` | 建任务 `{"prompt":"...","extra":""}` → 202 + `{id}` |
| GET | `/api/jobs` | 任务列表 |
| GET | `/api/jobs/{id}` | 任务详情（status/chart_url/log_tail/error） |
| GET | `/api/jobs/{id}/chart` | 返回生成的 HTML 图表 |
| GET | `/` | 前端页面 |

### 2.6 同一局域网内的其他主机访问

默认启动绑定 `127.0.0.1`（仅本机可访问）。要让局域网内其他主机访问，需三步：

**① 改为监听所有网卡（0.0.0.0）**

把启动命令里的 `--host 127.0.0.1` 改成 `--host 0.0.0.0`。涉及三处：

- `run.cmd`：`... python.exe -m uvicorn main:app --host 0.0.0.0 --port 8787`
- `start.ps1`：同样把 `--host 127.0.0.1` 改成 `--host 0.0.0.0`
- 方式 C（纯命令行）：
  ```powershell
  cd D:\AIVideoFactory\AssetByCodex\AssetPipeline\AssetPipeline\chat2chart\backend
  ..\.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8787
  ```

**② 查本机局域网 IP**

```powershell
ipconfig
# 找「IPv4 地址」一行，例如 192.168.1.100
```

**③ 放行防火墙端口（管理员 PowerShell 执行一次即可）**

```powershell
New-NetFirewallRule -DisplayName "chat2chart-8787" -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow
```

然后其他主机在浏览器访问：

```text
http://192.168.1.100:8787
```

**注意事项**

- 前端请求使用相对路径同源访问，**无需额外 CORS 配置**。
- 本机自身仍可用 `http://localhost:8787` 访问。
- 产品目前**没有登录 / 鉴权**，仅建议在可信内网开放；**不要直接暴露到公网**。
- 若换端口，`.env` 的 `C2C_PORT` 与防火墙放行端口需同步修改。

```powershell
# 查看 8787 端口占用 / 进程
Get-NetTCPConnection -LocalPort 8787 -State Listen

# 停止服务（按 pid 替换）
taskkill /PID <pid> /F

# 重新启动

```

- 查看单任务运行日志：任务详情接口返回的 `log_tail`，或磁盘文件 `chat2chart\data\jobs\<job_id>\log.txt`
- 清理历史任务（可选，谨慎）：`Remove-Item chat2chart\data\jobs\* -Recurse -Force`
- 无 token 冒烟测试：设 `$env:C2C_FAKE = "1"` 后启动，任务会用桩逻辑快速产出 `chart.html`，用于验证 HTTP 链路

### 3.3 提交代码到公司仓库

公司仓库 remote：`https://github.com/ztnb0/AssetPipeline.git`（分支 `main`）。

**重要约束**
- `.env`（含模型/路径配置）、`data/`（任务数据）、`.venv/`、`__pycache__` 均已被 `chat2chart\.gitignore` 忽略，不会误提交。
- `auth.json` 里的 API key、`.env` 里的敏感项**永远不要提交**。
- 本仓库当前还存在一些与本产品无关的改动（如 `backend/app/*`、`frontend/app/page.tsx`、根目录若干 `.md`、`中美黄金储备对比.html` 等）。提交时**只 stage 与 chat2chart 相关的文件**，避免把无关改动混入。

```powershell

# 1) 先查看变更，确认要提交的内容
```

**新机器部署 checklist（首次部署到其他主机时）**

1. 装 Python 3.11、Node/npm
2. `npm i -g opencode-ai` 并 `opencode auth login`（或放好 `auth.json`）
3. clone lieflat-charts 到 `~/.claude/skills/lieflat-charts`
4. 在 python 3.11 中 `pip install akshare`
5. `cd chat2chart; Copy-Item .env.example .env` 并按新机器路径改 `OPENCODE_BIN`（和必要的 `C2C_MODEL`）
6. `.\start.ps1` 启动
